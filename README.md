# Zunavio Studio Website

Official GitHub Pages website for Zunavio Studio.

## GitHub Pages

Repository: `nourferhane/zunavio`

To publish:

1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**.
4. Save.

The site should then be available at:

`https://nourferhane.github.io/zunavio/`

## Book cover files
